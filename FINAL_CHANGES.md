# Finale update — terminology, autocomplete and onward journey

- UI uses Ride Initiator and Ride Joiner rather than Passenger A / B.
- Case-insensitive prefix search for pickup and destination; explicit selection still required.
- Homepage example uses alphabetic A–E route and ₹20, ₹10, ₹10, ₹10 shared-auto segments; the Ride Initiator starts at ₹100, with a ₹50 shared-auto minimum.
- For an initiator home (e.g. Aher Garden) before their selected fare anchor (Walhekarwadi), a joiner travelling to the downstream anchor requires the driver to explicitly check onward-journey consent when accepting. The initiator must still be dropped at their actual home. Driver may complete the initiator booking before the joiner only if the onward continuation was explicitly approved.
- Driver route progress and roadside geometry are STILL simulated. The checkbox is driver consent, not GPS verification, and the application does not enforce real-world drop-off.
- No live Uber quotes or payment gateway.
