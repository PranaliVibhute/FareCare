# FareCare: New VIT Pune Gate to Mandai route

Stops in order: VIT Pune Gate → Bibwewadi → Swargate → Mandai.

| Segment | Fare |
|---|---:|
| VIT Pune Gate → Bibwewadi | ₹10 |
| Bibwewadi → Swargate | ₹10 |
| Swargate → Mandai | ₹10 |
| **VIT Pune Gate → Mandai** | **₹30** |

The two existing routes remain unchanged. The Ride Initiator's demo private fare remains ₹100; Ride Joiners pay summed segment fares. Map pins are geocoded using OpenStreetMap/Nominatim; the exact VIT gate position should be visually checked. Browser and live geocoding testing have not been performed.
