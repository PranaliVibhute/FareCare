Driver GPS tracking uses browser watchPosition and updates the map marker continuously as the browser provides fixes. Location permission is mandatory for driver dispatch actions in this demo. Browser geolocation works on localhost or HTTPS; device and browser must support location. A GPS fix older than 60 seconds disables dispatch actions. Nearest fare anchor is updated periodically and synced to simulated dispatch. Actual road geometry, path adherence, and production authentication are NOT implemented. Driver location is not continuously transmitted to the backend; the backend receives only the matched fare anchor. Stop geocoding requires network access.
